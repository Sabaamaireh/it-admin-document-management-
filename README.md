# it-admin-document-management-
IT Admin Document Management & Excel Portfolio Project
Project overview
A small, fictional IT office administration project demonstrating spreadsheet-based asset tracking, structured record keeping, and document organization. All names, devices, and IP addresses are sample data created for practice.
Objectives
Maintain a structured IT asset register.
Track device assignment, operating system, IP address, and update status.
Use Excel tables, filters, data validation, and conditional formatting.
Summarize asset status with formulas in a dashboard.
Demonstrate clear file organization and basic documentation practices.
Files
`IT_Asset_Register.xlsx` — asset register and summary dashboard.
`sample_documents/` — folder for sample administrative documents you create.
`Document_Register.csv` — document tracking log.
`README.md` — project description and usage notes.
Excel features
Structured Excel Table with filters and alternating row styles.
Frozen header row.
Dropdown list for update status and device type.
Conditional formatting for Updated, Pending, and Overdue.
Dashboard formulas: `COUNTA`, `COUNTIF`.
Suggested document-management exercise
Create 3 fictional documents and store them in `sample_documents/`:
`Meeting_Minutes_2026-10-16.docx`
`IT_Asset_Update_Report_2026-10-16.docx`
`Supplier_Follow_Up_Email_2026-10-16.docx`
Then fill in `Document_Register.csv` with document title, category, owner, created date, status, and file path.
Important
This is a practice portfolio project, not paid employment or a real company asset register. Do not enter real personal data or confidential company information.
